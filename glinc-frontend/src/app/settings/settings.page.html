Información general y créditos. Cómo está construido el ecosistema. ¿Tienes un problema o sugerencia?

{{ appNombre }} es una aplicación de monitoreo de glucosa en tiempo real para múltiples pacientes que usan el sensor FreeStyle Libre de Abbott.

Permite a un cuidador (familiar, profesional sanitario) ver en un único panel la última lectura de cada paciente, su tendencia y el histórico de los últimos días.

Glinc está formado por tres módulos que cooperan entre sí. Cada uno tiene su propio README en la carpeta del proyecto.

Módulos del ecosistema
  1. 1
    cgm-bridge-service
    Microservicio Node.js + TypeScript. Hace de puente entre la API privada de LibreLinkUp (Abbott) y el backend de Glinc. Documentación: Swagger UI en /docs del puerto 3001.
  2. 2
    glinc-backend
    API REST en Java + Spring Boot. Persiste las lecturas de glucosa en PostgreSQL y gestiona la autenticación. Documentación: Swagger UI en /docs del puerto 8080.
  3. 3
    glinc-frontend
    Aplicación web Angular (esta misma). Funciona en cualquier navegador moderno.
¿Cómo se conectan?

El frontend habla únicamente con el backend (puerto 8080). El backend, a su vez, consulta al bridge (puerto 3001) cuando necesita datos frescos de LibreLinkUp. Las credenciales del paciente solo viajan durante el inicio de sesión y nunca se almacenan en disco.

Glinc es un proyecto académico mantenido por una sola persona. Si encuentras un fallo, tienes una idea o necesitas ayuda con el inicio de sesión, contacta directamente con el autor.
